## Original Creator

**Deadzoke**

Creator of the original [Ignite HUD](https://www.curseforge.com/minecraft/mc-mods/ignitehud) mod — the RPG-style HUD that Reignited HUD is based on. The concept, visual design language, and original HUD element set originate from their work.

---

## Heria Zone

**MSymbios** ([@MSymbios](https://github.com/MSymbios)) — *Heria Zone*

Full rebuild and modernisation of Ignite HUD. All 1.21.1 code, multi-loader architecture, and new features:

- Complete codebase rewrite for modern Minecraft (1.16.5 → 1.21.1)
- Multi-loader architecture (Fabric, Forge, NeoForge)
- All HUD elements — Health Bar, Hunger Bar, Experience Bar, Breathing Bar, Mount Information, Equipment Slot Display, Item in Hand Display, Player Skin, Player Username, Clock, Status Effects
- Configuration system via Mod Menu (Fabric) and Configured (Forge)
